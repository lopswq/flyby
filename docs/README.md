# Flyby

- 고등학교 국어 지문 발표용 HTML 자료 프로젝트임.
- 현재 구현 기준: [10장 대본·애니메이션 설계](md/flyby_script_and_animation.md)와 원본 PPTX임. 이후 사용자 피드백을 우선 반영함.
- 실제 발표용 낭독은 [5분 발표 대본](md/presentation_script.md)을 사용함. 낭독문은 4,760자에서 1,388자로 약 71% 줄임. 현재 HTML 10장·30단계와 Space 29회 위치는 유지함. 이전 설계의 6~8분 목표보다 최신의 최대 5분 요청을 우선함.
- 기본 1배속에서 낭독·운동 대기·조작을 합쳐 5분 이내를 목표로 함. 계획용 추정은 약 4분 15초~4분 50초이며 실제 낭독 시간은 사용자 리허설에서 확인함.
- 인쇄는 [A4 낭독 대본](presentation_script_a4.pdf)을 사용함. 세로 2쪽·본문 11pt임. 낭독문과 Space·대기만 수록함. A4·실제 크기 100%로 출력함.
- `presentation/index.html`에 본문 10장·30개 수동 단계와 시작·끝의 남색 빈 화면 구현함. 빈 화면 포함 12장·32단계임. 본문 번호 01~10은 유지함.
- 현재 상태: 시작·끝 빈 화면과 짧은 장 전환 추가함. 06 전체 이동선은 설명용 경로임. 실제 브라우저 조작·전환 체감은 사용자 확인 대기 중임.
- 기존 단일 장면 프로토타입 2종도 보존함.
- 원본 10장 PPTX·PDF는 애니메이션 없는 자료로 보존함. 애니메이션은 HTML에서 재생함.

- 경유 단계는 행성 중심에서 멈추지 않고 옆을 스쳐 지난 뒤의 위치까지 재생함. 혜성의 실제 위치를 그림에서 추정했다고 주장하지 않음.
- 원본 이미지의 지구 중심 `(1470, 1585)`·화성 중심 `(1488, 1779)` 픽셀을 같은 자르기 변환으로 투영함. 이미지 위치·근접 통과·강조 표시는 이 좌표를 공유함. 지구 통과 거리 20px·화성 18px 사용함. 기존 44px의 먼 통과와 과도하게 큰 기체를 수정함. 기체는 다른 도식의 40% 크기로 표시함.
- 전체 여정 화면 진입 시 지구 출발을 보여줌. 출발·첫 경유는 같은 이동 시각표를 분할해 위치·방향·속력을 이어감. 구간 소요 시간은 경로 길이와 속력으로 계산하며 구간마다 정해진 초에 맞춰 가속하지 않음. 수동 모드에서만 입력 대기를 위해 구간 끝에 멈춤.
- 근접 통과는 뉴턴 중력 적분의 순간 속력을 같은 배율로 적용함. 행성에 접근할수록 빨라지고 최근접점 이후에는 느려짐. 사진 위 장거리 설명용 곡선은 순항 속력과 근접 통과 속력을 연결함. 사진 전체가 실제 로제타의 태양 기준 속력 데이터인 것은 아님.
- 경유 구간마다 적용하던 출발·정지 시간 보간 제거함. 구간 경계의 위치·방향·0이 아닌 속력을 연결함. Ctrl 자동 모드에서는 프레임 시계와 남은 시간을 다음 구간으로 넘겨 멈춤 없이 진행함.
- 화성 이탈 직후 짧은 제어점 때문에 되꺾이던 경로 수정함. 이탈 방향으로 넓게 진행한 뒤 지구 접근 경로로 연결함. 근접 통과의 뉴턴 가속도에서 곡률·속력의 거리 기울기를 구해 장거리 곡선의 경계 조건으로 사용함.
- 장거리 경로는 위치·접선·곡률이 이어지는 5차 Bezier로 구성함. 표본 사이의 이동도 같은 조건으로 보간해 작은 직선 모서리를 제거함. 접선·법선 가속도의 경계 불연속을 줄인 설명용 경로이며, 전체 구간을 실제 천체력으로 적분한 로제타 궤도는 아님.
- 원리·방법·접근 조건의 도식도 같은 물리 시간 배율로 재생함. 같은 통과를 장면마다 다른 초에 맞춰 재생하던 속력 차이 제거함.
- 지난 궤적은 구간별 색과 점선으로 계속 표시함. 왼쪽 경유 목록에도 같은 색의 표시를 연결함.
- 다음 문구에 새 운동이 없으면 즉시 공개함. 새 운동이 연결된 단계는 현재 재생 후 문구·그림을 함께 한 번 전환함. 05의 방향·거리·타이밍과 06의 경유 목록이 실제 운동보다 앞서 진행되지 않게 함.
- Space·전진 방향키·PageDown은 같은 기능임. 현재 애니메이션에 붙은 문구가 모두 나오고 재생만 남았을 때, 320ms 안의 두 번째 입력으로 남은 재생을 완료하고 다음 장면으로 즉시 진행함. 다음 장면은 같은 슬라이드의 다음 운동 단계일 수도 있음. 첫 입력으로 마지막 문구가 공개된 경우에도 두 번째 입력으로 건너뛸 수 있음. 현재 운동의 문구가 더 남았으면 문구부터 공개함. 키를 길게 눌러 발생하는 반복 입력은 제외함.
- Shift 한쪽을 누르는 동안 2배속, 왼쪽·오른쪽을 함께 누르면 4배속으로 진행함. 두 번째 Shift가 `repeat=true`로 전달돼도 기록함. 같은 키의 반복은 배속을 중복하지 않음. 한쪽 해제 이벤트가 오면 2배속, 모두 놓으면 1배속으로 복귀함. 브라우저가 한쪽 해제 이벤트를 생략하면 양쪽을 모두 놓아 배속을 해제함. 창 포커스 이탈·탭 숨김 때도 배속을 해제함.
- 06 전체 여정 화면에서 Ctrl을 한 번 누르면 자동 진행·반복을 켜고 다시 누르면 끔. 경유 구간 사이에서 감속·정지 없이 다음 문구·운동으로 이어지고 마지막 구간 뒤에는 지구 출발부터 반복함. 자동 반복 여부는 화면에 표시하지 않음. 다른 장으로 나가면 자동 모드를 해제함.
- 자동 모드를 끄면 현재 구간은 끝까지 재생한 뒤 유지함. 기본 수동 모드에서는 다음 요청이 있을 때만 구간 끝에서 한 단계 이어감.
- 각 장의 숨김 `aside.speaker-notes`는 10장 설계의 참고용 대본임. 실제 5분 낭독은 위 Markdown·PDF를 기준으로 함.

- 임시 `flyby-check-curvature.cjs`로 모든 연결점과 보간 표본의 접선·곡률 및 경유 구간의 가속도 연결을 검사함. 화성 이탈 직후 0.2초의 60 FPS 프레임당 최대 방향 변화는 약 73.44도에서 약 0.60도로 감소함. 전체 경로의 최대 프레임당 변화는 약 4.53도임. 실제 화면 체감은 사용자 확인 필요함.
- 사진의 근접 통과 표시 속력은 접근 약 167.34px/s → 최근접 약 203.94px/s → 이탈 약 167.34px/s임. 적분한 행성 기준 속력을 공통 배율로 환산한 값이며 실제 로제타의 km/s 수치가 아님.
- 최신 이미지 정렬 검사에서 지구 최근접 거리 20px, 화성 18px 확인함. 행성 그림과 기체가 겹치지 않고 가까이 통과하며, 강조 중심·경로 목표·원본 픽셀 변환이 같은 위치인지 검사함. 모든 경로가 태양 중심에서 50px 이상 떨어지는지 검사함. 기존 44px 통과 검사 수치는 이전 구현의 기록임.
- Space·전진 방향키의 같은 입력 흐름을 검사함. 같은 운동의 문구가 남으면 공개를 우선하고, 마지막 문구 공개 후 150ms 두 번째 입력은 건너뛰며, 500ms 간격은 재생 대기로 처리함. 05·06의 같은 슬라이드 안에서도 다음 운동으로 즉시 넘어가는지 검사함.
- Ctrl 토글·길게 누르기 반복 무시·키를 놓은 뒤 모드 유지·전체 여정 반복·해제 후 구간 끝 정지·탭 숨김 후 재개·장 이탈 시 해제·모션 감소 설정에서의 자동 진행을 대체 객체로 검사함.
- 임시 `flyby-check-keys.cjs`에서 좌우 Shift를 구분해 1→2→4→2→1배속과 반대쪽부터 놓기를 검사함. 반복 입력 중복 방지·포커스 이탈·탭 숨김 시 초기화·4배속 구간 전환·Ctrl 모드의 표시 문구 제거 확인함.
- 방향·거리 비교 모델도 무충돌·행성 기준 전후 속력·비에너지 오차를 수치 검사함.
- 실제 브라우저 화면·속도감·가독성·발표 시간은 사용자 확인 필요함. 아래 2026-10-19 기록은 이전 20장 시안의 이력임.
- 5분 대본의 10장·30단계·Space 29개 지시를 현재 코드의 단계 전환과 대조함. 각 지시의 시작·도착 상태와 마지막 결론 도달 확인함. 실제 낭독·브라우저 조작 검사가 아님.
- `node "$env:TEMP/flyby-check-script-with-blanks.cjs"`: 시작 빈 화면에서 표지를 연 뒤 기존 Space 29개 지시의 시작·도착 상태 및 끝 빈 화면 이동 검사 통과함. 5분 A4 대본 2쪽 전체 렌더링·문장 보존·Space 번호 점검함. 실제 인쇄 검사는 아님.

- `node "$env:TEMP/flyby-check-shift-repeat.cjs"`: 두 번째 Shift의 `repeat=true` 입력을 양쪽 순서로 검사함. 1→2→4→2→1배속 시계, 마지막 해제 이벤트만 오는 경우의 초기화, Ctrl 자동 여정의 4배속 구간 연결 검사 통과함. 실제 키보드 입력 확인은 사용자 수행 항목임.

### 06 원본 그림·경로 대조 결과 — 2026-10-21

- 사용자 요청에 따라 원본 PPTX·PDF·ESA 포스터와 코드 경로를 대조함. 브라우저를 실행한 검사는 아님.
- `rosetta-journey.jpg`와 원본 PPTX의 `ppt/media/image6.jpeg`는 바이트가 일치함. [ESA 원본 포스터](https://www.esa.int/ESA_Multimedia/Images/2013/12/From_launch_to_encounter)와 같은 자료임.
- 원본의 위 13%·아래 60% 자르기를 사용함. PPT 프레임 가로세로 비율은 약 2.145, HTML은 약 2.590임. HTML은 포스터 자르기의 원래 비율을 유지하며 같은 폭에서 PDF보다 약 17% 낮게 보임.
- **미해결: 덧그린 경로는 포스터의 노란 궤도선을 추적한 것이 아님.** 임의의 장거리 제어점과 근접 통과 모델을 연결한 경로임. 이미지 위에 겹쳐 비교하면 큰 차이가 보임.
- 당시 첫 구간은 그림의 태양 중심 약 `(250, 204)`에서 최소 약 8.16px까지 접근하여 태양 표면을 가로지름. 이후 연결 경로를 바꿔 첫 구간의 중심 거리를 약 63.56px로 수정함. 전체 구간의 태양 회피 검사 통과함.
- 모든 지구·화성 경유를 고정된 행성 그림 한 점으로 연결함. 실제 서로 다른 시점의 행성 위치는 재현하지 않음. 장거리 구간에는 태양 중력과 행성 공전 계산이 없음.
- 앞선 연속성·속도·곡률 검사는 움직임의 연결을 검사한 것임. 원본 궤도와의 일치 또는 전체 여정의 물리적 타당성을 증명하지 않음.
- 최초 대조 요청에서는 원인 조사와 조작 기능만 수정함. 이후 사용자 지적에 따라 원본 픽셀의 행성 중심 재지정·단일 좌표 변환·통과 거리 축소·기체 축소·태양 회피 경로 수정함. 원본의 노란 선을 그대로 추적하거나 실제 천체력을 재현한 경로는 아님.

### 물리 표현의 범위와 근거

- 발사는 지표 근처 수직 상승의 교육용 모델임. 특정 발사체·전체 궤도 진입·실제 발사 시간의 재현이 아님. 초기 추력비와 표시 시간은 힘겨운 이륙을 설명하기 위해 정한 값임.
- 진동·땀은 로켓의 힘겨움을 전달하는 과장임. 중력이 흔들림을 직접 발생시킨다는 뜻이 아님.
- 중력 통과는 기존 뉴턴 중력의 제한 2체 모델임. 큰 질량의 행성을 일정 속도로 근사하며 태양 중력·행성의 작은 반작용은 생략함. 실제 임무의 정밀 궤도 계산이 아님.
- [NASA — Forces at Liftoff](https://www.grc.nasa.gov/www/k-12/VirtualAero/BottleRocket/airplane/rktlo.html): 이륙 시 추력과 무게의 차이에 따른 가속도.
- [NASA — Four Forces on a Rocket](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/four-rocket-forces/): 추력·무게·공기력.
- [NASA — A Gravity Assist Primer](https://science.nasa.gov/learn/basics-of-space-flight/primer/): 행성 기준 전후 속력과 태양 기준의 에너지 변화.

### v1의 물리 모델

- 뉴턴 중력 `a = -μr / |r|³` 기반 계산임.
- 태양 기준에서 행성은 13 km/s로 직선 이동함.
- 목성과 비슷한 중력 계수 `μ = 126,686,534 km³/s²`와 반지름 `69,911 km`를 사용한 교육용 예시임.
- 태양 중력·다른 천체·행성의 미세한 반작용은 생략함.
- 실제로는 행성의 공전 에너지가 극히 조금 감소함. 일정 속도는 큰 질량을 가진 행성에 대한 근사임.
- 고정 10초 간격 velocity Verlet 적분과 화면 보간을 분리함.
- 재생 속도는 시간 진행만 변경함. 계산 간격은 유지됨.
- 행성·탐사선의 표시 크기는 가독성을 위해 확대함. 표시 수치는 물리 계산값임.
- 행성 중심 거리가 출발 거리 이상으로 회복된 이탈 상태에서 종료함.
- 행성 기준 속력은 같은 거리에서 전후가 거의 같고, 태양 기준 속력은 증가하는 조건임.
- 화면 배치와 재생 시간 계산용 예비 적분을 수행함. 실제 재생 상태는 별도로 적분함.
- 실제 임무 궤도나 정밀 태양계 모형이 아님.

### 코드 검사와 과거 확인 기록

- v1 수치 검사: 프로젝트 루트에서 `node simulations/v1/check-physics.cjs` 실행함.

- 이전 기록의 v1 최근접 중심 거리 약 209,795 km, 표면 고도 약 139,884 km임.
- 이전 기록의 v1 비에너지 최대 상대 오차는 약 0.000107%임.
