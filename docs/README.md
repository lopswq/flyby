## 전체 HTML 발표 실행

- [presentation/index.html](../presentation/index.html)을 브라우저에서 직접 열어 실행함.
- HTML·CSS·일반 JavaScript 상대 경로로 연결함. 설치·빌드·서버·인터넷이 필요하지 않음.
- Windows 기본 한글 글꼴을 우선 사용함. 원격 글꼴·CDN·이미지·API를 불러오지 않음.
- 1920×1080 고정 16:9 무대를 화면에 맞춰 비율 유지 확대·축소함.
- 방향키 또는 Space로 발표자가 직접 진행함. 자동으로 다음 장에 넘어가지 않음.

| 키 | 기능 |
| --- | --- |
| 오른쪽 방향키 / Space / PageDown | 현재 장의 다음 단계 공개. 마지막 단계이면 다음 장 이동 |
| 왼쪽 방향키 / PageUp | 이전 장의 첫 단계로 이동 |
| 마지막 장에서 다음 키 | 종료 화면 유지 |

- 03·08·09·14·15·17·19장은 다음 키로 문구나 장면을 단계별 공개함.
- 11장은 접근·이탈 재생 후 처음과 마지막 속력 비교 문구로 바뀜.
- 03·07·11·12장만 진입 시 한 번 움직이고 결과 그림을 유지함. 자동 반복 없음.
- 나머지 16장은 문구·정지 도식·수동 단계 공개로 구성함. 대기 중 그리기 루프 없음.
- 장면 이탈 시 이전 그리기 요청을 취소함.
- 탭이 숨겨지면 그리기 요청을 중지하고 복귀 시 숨겨진 시간을 건너뛰지 않고 이어감.
- 모션 감소 설정에서는 대표 정지 상태를 표시함. 수동 단계 공개는 유지함.
- 브라우저의 전체 화면 기능은 사용자가 직접 적용함.
- 발표자 노트는 HTML의 슬라이드별 `aside.speaker-notes`에 보관함. 기본 청중 화면에는 표시하지 않음.
- 노트는 편집기에서 `presentation/index.html`을 열어 확인 가능함.

### 내용과 남은 확인

- 도입 질문 → 지구 탈출과 중력 웅덩이 → 중력 이용 → 가속·감속·방향 전환 → 두 관측 기준 → 접근 조건 → 로제타 경유 → 환승역 비유 → 결론의 20장 흐름임.
- 07·11·12장 등은 뉴턴 중력의 고정 간격 적분 경로를 사용한 교육용 장면임.
- 09장 가감속은 적분 결과의 전후 속력으로 같은 시간 동안의 이동 거리를 비교함. 두 줄은 한 통과의 전후 비교이며 실제 궤도를 그린 것이 아님.
- 경로 비교·조건 설명·로제타 노선도는 설명용 곡선임. 실제 임무 데이터로 표시하지 않음.
- 로제타 사건은 JavaScript의 `ROSETTA_EVENTS`에서 순서·연도·천체를 함께 관리함.
- 교과서 자료 폴더는 비어 있음. 원 지문·교재명·쪽수·직접 인용을 확인했다고 표시하지 않음.
- 실제 브라우저 화면·키 조작·애니메이션 체감·교실 가독성·총 발표 시간은 사용자 확인 필요함.

## 현재 작업 방향

- 지문 설명을 중심으로 구성함.

- 외부 글꼴을 불러오지 못하면 기본 글꼴로 표시됨.
- 밝은 설명 영역과 어두운 개념도 영역을 사용하는 기존 시안임. 전체 발표의 디자인이 최종 확정된 것은 아님.

## 이전 시뮬레이션 v1

- [simulations/v1/flyby.html](../simulations/v1/flyby.html)을 브라우저에서 직접 열어 실행함.
- 개념의 수치와 벡터를 관찰하는 이전 실험용 버전임. 현재 발표 화면의 요구사항과 구분함.
- 1920×1080 화면을 비율 유지하여 확대·축소함.
- 별·행성·탐사선은 Canvas로 생성함. 외부 이미지가 필요하지 않음.

| 조작 | 기능 |
| --- | --- |
| 재생 / 일시정지 또는 Space | 시작·정지·이어서 재생 |
| ↺ 또는 R | 일시정지된 시작 상태로 초기화 |
| 0.5× / 1× / 2× | 시간 진행 배율 변경 |
| 이동 궤적 | 지나온 경로 표시 전환 |
| 속도 벡터 | 탐사선·행성·비교 벡터 표시 전환 |

- 이탈 완료 후 자동 정지함. `다시 보기`로 재생 가능함.
- 브라우저 탭이 숨겨지면 자동 일시정지함.
- 모션 감소 설정에서는 최근접 카메라 확대를 생략함.
- 1×에서 약 40초 동안 약 40시간의 만남을 압축해 재생함.

### v1의 물리 모델

- 뉴턴 중력 `a = -μr / |r|³` 기반 계산임.
- 태양 기준에서 행성은 13 km/s로 직선 이동함.
- 목성과 비슷한 중력 계수 `μ = 126,686,534 km³/s²`와 반지름 `69,911 km`를 사용한 교육용 예시임.
- 태양 중력·다른 천체·행성의 미세한 반작용은 생략함.
- 실제로는 행성의 공전 에너지가 극히 조금 감소함. 일정 속도는 큰 질량을 가진 행성에 대한 근사임.
- 고정 10초 간격 velocity Verlet 적분과 화면 보간을 분리함.
- 재생 속도는 시간 진행만 변경함. 계산 간격은 유지됨.
- 행성·탐사선의 표시 크기는 가독성을 위해 확대함. 표시 수치는 물리 계산값임.
- 행성 중심 거리가 출발 거리 이상으로 회복된 이탈 상태에서 종료함.
- 행성 기준 속력은 같은 거리에서 전후가 거의 같고, 태양 기준 속력은 증가하는 조건임.
- 화면 배치와 재생 시간 계산용 예비 적분을 수행함. 실제 재생 상태는 별도로 적분함.
- 실제 임무 궤도나 정밀 태양계 모형이 아님.

### 코드 검사와 과거 확인 기록

- v1 수치 검사: 프로젝트 루트에서 `node simulations/v1/check-physics.cjs` 실행함.
- 검사 스크립트는 같은 폴더의 `flyby.html` 내부 물리 코드를 읽음. v2나 전체 발표를 검사하지 않음.
- 이전 기록의 v1 결과: 태양 기준 23.85 → 32.99 km/s, 행성 기준 전후 약 20.00 km/s임.
- 이전 기록의 v1 최근접 중심 거리 약 209,795 km, 표면 고도 약 139,884 km임.
- 이전 기록의 v1 비에너지 최대 상대 오차는 약 0.000107%임.
- 이전 기록의 v1 시간 진행 모의 계산: 30 FPS·0.5×, 60 FPS·1×, 144 FPS·2×에서 같은 최종 상태임.
- 이전 기록의 v2 확인: JavaScript 구문, 물리 계산의 충돌 여부와 비에너지 오차, DOM·Canvas 대체 객체를 이용한 자동 반복·탭 숨김·모션 감소 처리 점검임.
- 위 기록은 과거 코드 점검 결과임. 실제 브라우저 동작·화면 배치 검수를 대신하지 않음.
- 실제 화면 배치·반복 속도·사용 조작은 사용자가 확인함.
