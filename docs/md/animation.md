# 플라이바이(Flyby) 우주 탐사 애니메이션 프로토타입 제작

## 1. 목표

고등학교 국어 발표에서 사용할 HTML 기반 우주 탐사 애니메이션을 제작한다.

전체 발표 자료를 제작하기 전에 **플라이바이(Gravity Assist) 원리를 시각적으로 설명하는 애니메이션 한 장면**만 구현한다.

단순한 PPT 애니메이션이 아니라, 우주 탐사 시뮬레이션을 보는 듯한 고품질의 인터랙티브 애니메이션을 목표로 한다.

## 2. 기술 스택

- HTML, CSS, JavaScript
- Three.js 또는 Canvas/SVG 등 적합한 기술 자유롭게 선택
- 별도의 서버 없이 로컬에서 실행 가능하도록 구성
- 1920×1080, 16:9 화면 기준
- 부드러운 애니메이션(가능하면 60FPS)
- 외부 이미지에 의존하지 않고도 기본 화면이 정상적으로 표시되도록 구현

## 3. 화면 디자인

전체적인 디자인은 NASA 우주 탐사 시뮬레이션과 과학 다큐멘터리를 참고한다.

- 배경: 어두운 우주 공간과 은은한 별
- 중앙: 입체감 있는 행성
- 탐사선: 작은 우주 탐사선 모델
- 이동 경로: 빛나는 곡선 또는 점선
- 속도 벡터: 화살표로 표시
- 글씨: 최소한의 설명과 수치만 표시
- 전체적으로 세련되고 과학적인 분위기

너무 게임처럼 보이지 않도록 한다.

## 4. 핵심 애니메이션

### 장면 1. 탐사선 접근

- 행성이 화면 중앙 부근에 위치한다.
- 행성은 일정한 속도로 공전 방향을 따라 이동한다.
- 탐사선이 화면 왼쪽에서 등장한다.
- 탐사선의 뒤쪽에 이동 궤적이 표시된다.
- 탐사선의 진행 방향과 속도 벡터를 표시한다.

### 장면 2. 중력에 의한 궤도 변화

- 탐사선이 행성에 접근한다.
- 행성의 중력으로 탐사선의 이동 경로가 자연스럽게 휘어진다.
- 탐사선은 행성에 충돌하지 않고 근접 통과한다.
- 행성과 탐사선의 거리에 따라 탐사선의 가속도가 변한다.
- 탐사선의 실제 이동 속도에 맞춰 애니메이션을 구현한다.
- 이동 경로가 실시간으로 그려진다.

### 장면 3. 플라이바이 후 이탈

- 탐사선이 행성을 통과한 후 새로운 방향으로 이동한다.
- 태양 기준 탐사선의 속도가 증가한 것을 보여준다.
- 접근 전과 이탈 후의 속도 벡터를 비교한다.
- 화면에 'Gravity Assist'라는 텍스트가 나타난다.
- 탐사선은 엔진을 분사하지 않고 이동한다.

## 5. 물리학적 정확성

이 애니메이션은 플라이바이의 원리를 설명하는 교육용 시뮬레이션이다.

단순히 미리 정해진 곡선 위로 탐사선을 움직이는 방식보다 실제 중력에 기반한 계산을 우선한다.

- 뉴턴의 만유인력 법칙을 기반으로 탐사선의 운동을 계산한다.
- 행성은 태양 기준 좌표계에서 일정한 속도로 이동하도록 단순화한다.
- 탐사선은 행성의 중력에 의해 가속된다.
- 행성 기준에서는 접근 전후의 원거리 속력이 거의 같도록 한다.
- 태양 기준에서는 행성의 운동에 의해 탐사선의 속력이 증가하는 조건을 구성한다.
- 에너지와 운동량 교환의 개념을 왜곡하지 않는다.
- 화면에 표시하는 속도 수치는 실제 시뮬레이션 계산 결과를 사용한다.
- 물리 계산은 고정 시간 간격으로 수행하고, 렌더링과 분리한다.

실제 태양계의 크기와 거리를 그대로 재현할 필요는 없으며, 교육용으로 적절하게 축척을 조정한다.

## 6. 인터랙션

화면 하단에 다음 기능을 제공한다.

- 재생 / 일시정지
- 처음부터 다시 보기
- 애니메이션 속도 조절(0.5×, 1×, 2×)
- 탐사선 이동 궤적 표시 ON/OFF
- 속도 벡터 표시 ON/OFF

추가로 다음 수치를 표시한다.

- 탐사선의 현재 속력(태양 기준)
- 탐사선과 행성 사이의 거리
- 플라이바이 전후의 속력 변화

## 7. 애니메이션 연출

- 탐사선의 움직임이 부드러워야 한다.
- 행성은 단순한 원이 아니라 입체감 있게 표현한다.
- 탐사선의 이동 궤적은 시간이 지남에 따라 나타난다.
- 행성에 가까워질수록 궤적이 크게 휘어지는 모습이 명확해야 한다.
- 탐사선이 행성을 통과할 때 카메라가 약간 확대되는 연출을 추가한다.
- 중요한 순간에는 애니메이션을 일시정지하여 설명할 수 있어야 한다.
- 과도한 이펙트보다 물리적 움직임을 시각적으로 명확히 보여주는 것을 우선한다.

## 8. 구현 범위

이번 작업에서는 **전체 발표 자료를 만들지 않는다.**

플라이바이 애니메이션 한 장면만 구현한다.

프로토타입을 실행했을 때 다음 순서가 자연스럽게 연결되면 된다.

탐사선 접근 → 중력에 의한 궤도 변화 → 행성 근접 통과 → 속도 변화 → 이탈

실제로 실행하고 확인할 수 있는 완성된 코드로 제작한다.

코드 구현 후 실행 방법을 안내하고, 가능한 경우 브라우저에서 직접 동작을 확인하여 오류를 수정한다.
